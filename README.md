# Aisan Tafeem Amair — Portfolio

Personal professional website for Aisan Tafeem Amair.

## Stack
- Next.js
- React
- CSS
- Vercel-ready

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Updating the portfolio

New projects can be added to the `projects` array in `app/page.js`.
